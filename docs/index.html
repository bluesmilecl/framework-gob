Framework Gob.cl · Tailwind 4

El framework oficial del Gobierno de Chile, reconstruido sobre Tailwind CSS 4: mismos lineamientos gráficos, mismos nombres de clase y componentes, con 369 íconos y sin jQuery.

Comenzando

Esta librería mantiene el sistema visual oficial (azul #006fb3, Roboto + Roboto Slab, esquinas rectas, línea azul/roja) y conserva los nombres de clase del framework original (.btn-primary, .card-news, .navbar…), por lo que el HTML existente se migra con cambios mínimos.

Tailwind 4 nativo

Tokens en @theme: bg-primary, text-tertiary, md: con breakpoints oficiales.

Más íconos

53 oficiales + 316 extra como máscaras CSS: heredan currentColor.

Sin jQuery

JS vanilla de ~9 KB (min) para colapsables, tabs, dropdown, modal y accesibilidad.

Instalación

Tres formas de usarlo, según tu proyecto.

1 · Proyecto con Tailwind CSS 4 (recomendado)

npm install tailwindcss @tailwindcss/vite gob-cl-tailwind
/* app.css — sin preflight: el reboot de Bootstrap ya viene en el core de gob.cl */
@import "tailwindcss/theme.css" layer(theme);
@import "gob-cl-tailwind/fonts.css";   /* Roboto + Roboto Slab auto-alojadas */
@import "gob-cl-tailwind";             /* tokens + core Bootstrap 4/gob.cl + íconos */
@import "tailwindcss/utilities.css" layer(utilities);

/* Opcionales */
@import "gob-cl-tailwind/compat.css";  /* utilidades Bootstrap 4 (m-*, p-*, d-*, flex…) + modo a11y-fonts */
@import "gob-cl-tailwind/next.css";    /* componentes nuevos de Bootstrap 6 (alpha) con identidad gob.cl */
// main.js
import "gob-cl-tailwind/js";        // colapsables, dropdown, tabs, modal, toolbar (data-toggle de Bootstrap 4)
import "gob-cl-tailwind/next/js";   // opcional: dialog, drawer, menu, combobox… (data-bs-toggle de Bootstrap 6)

Con esto tienes bg-primary, text-tertiary, border-accent, font-slab, md:… y todas las clases del framework original. Los componentes viven en @layer components, así que una utilidad de Tailwind siempre los puede sobrescribir (btn btn-primary p-2).

2 · CSS precompilado (sin build)

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/gob-cl-tailwind@4.0.0/dist/fonts.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/gob-cl-tailwind@4.0.0/dist/gob.min.css">
<!-- opcional: componentes nuevos de Bootstrap 6 -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/gob-cl-tailwind@4.0.0/dist/gob-next.css">
<script src="https://cdn.jsdelivr.net/npm/gob-cl-tailwind@4.0.0/dist/gob.min.js" defer></script>
<script type="module" src="https://cdn.jsdelivr.net/npm/gob-cl-tailwind@4.0.0/dist/next/bootstrap6.bundle.min.js"></script>

dist/gob.min.css es un reemplazo directo de gob.cl.css: el HTML oficial funciona sin cambios.

3 · Desde el repositorio

npm install
npm run build      # genera dist/ (CSS, JS, fuentes, íconos, docs)
npm run build:core # regenera src/core desde el CSS oficial (tools/build-core.mjs)

Accesibilidad

Cumple con los lineamientos de la guía de accesibilidad del Estado.

  • Alto contraste: añade la clase a11y-contrast a <html> (o usa el botón de la toolbar). Aplica el tema oficial del framework original a todos sus componentes. Para utilidades Tailwind y componentes Bootstrap 6 importa además gob-cl-tailwind/contrast-tokens.css.
  • Tamaño de texto: a11y-font-1 (20px) y a11y-font-2 (24px). Todo el sistema usa rem.
  • Foco visible en todos los elementos interactivos (:focus-visible) y enlace “Saltar al contenido” (.skip-link).
  • Movimiento reducido: se respeta prefers-reduced-motion.
  • Tabs con navegación por teclado (flechas, Home, End) y ESC cierra dropdown/modal.
